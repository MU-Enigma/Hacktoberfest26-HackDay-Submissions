## 🚀 Overview

**Washing MUchine** is a smart, interactive laundry management platform designed to streamline campus/shared washing machine usage. Users scan QR codes located on physical machines to instantly view real-time status, reserve slots, and track cycles without waiting in queues.

---

## ✨ Key Features

* 📱 **QR Code Interaction:** Quick access to specific machine controls via scan.
* 🌀 **Dynamic Theme & UI:** Washing machine drum animations, floating bubbles, and clear visual state feedback.
* ⚡ **Real-Time Status Tracking:** Instant visibility into machine availability and cycle progress.
* 🛠️ **Lightweight Stack:** Fast backend response with zero bloated client overhead.

---

## 🛠️ Tech Stack

* **Backend:** Python / Flask
* **Database:** SQLite
* **Frontend:** HTML5, Tailwind CSS, JavaScript
* **WSGI Server:** Gunicorn
* **Deployment:** Render
