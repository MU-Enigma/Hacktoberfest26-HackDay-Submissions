## Problem

In hostels, it's usually a struggle to find hot water to bathe, our project aims to help each other out in this aspect. 

## Solution

The basic idea is that people from each block will comment if the water available is hot or not and this feedback is averaged out and updated every 30 minutes based on the feedbacks received. 

## Technologies used

- Analyzed data received from students who shower.
